# site — the React source for docs/index.html and docs/explorer.html

The two hand-authored pages of the GitHub Pages site
(https://charith-reddy-pareddy.github.io/soccer-markov-nash/) are a small
Vite + React app. Everything else under `docs/` (`positions.html`,
`report.html`, `gallery.html`, the `.md` files, `figures/`, the PDFs) is
generated straight from Python by the scripts in `../scripts/` and is
untouched by this app.

- `src/Landing.jsx` — the landing page (`index.html`).
- `src/explorer/` — the interactive board explorer (`explorer.html`): place
  either player anywhere on any of four boards and read the live equilibrium
  policy and exact Q matrix (table or best-response graph), fetched from
  `docs/data/explorer.json`.
- `src/Nav.jsx`, `src/Footer.jsx` — shared chrome between the two pages.
- `src/theme.css` — design tokens. Light is the default; `src/useTheme.js` +
  `src/ThemeToggle.jsx` add an explicit dark-mode toggle, remembered in
  `localStorage`, independent of the visitor's OS setting.

## Data

`docs/data/explorer.json` is generated by `python scripts/explorer_data.py`
(`make explorer-data` from the repo root) — the exact `NashQIteration.
run_exact()` solve of every state on all four boards used in
`docs/positions.md`. Regenerate it whenever the game rules, reward, or
solver change; the explorer always reads whatever is on disk.

## Developing

```bash
npm install
npm run build   # writes ../docs/index.html, ../docs/explorer.html, ../docs/assets/*
```

There's no `npm run dev` workflow here: the explorer fetches
`docs/data/explorer.json` at runtime, and that file (plus every image the
landing page embeds) only exists inside `../docs/`, not inside `site/`. To
preview a change, build, then serve the real `docs/` folder:

```bash
npm run build
npx vite preview --outDir ../docs --port 5173
```

`npm run build` never deletes anything in `docs/` outside the files it
writes (`emptyOutDir: false` in `vite.config.js`), so the Python-generated
pages, figures, and PDFs are safe.

## Deploying

Nothing extra: GitHub Pages is already configured to serve `docs/` from
`main`. Commit the rebuilt `docs/index.html`, `docs/explorer.html`, and
`docs/assets/*` alongside the `site/` source and push — the next Pages build
picks it up automatically.
