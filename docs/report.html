Pure Nash Equilibria
for Soccer

Solving a two-player zero-sum Markov game with pure-strategy Nash Q-iteration — and finding where pure strategies quietly stop working.

Research question Can pure-strategy Nash equilibria be used to efficiently solve the soccer Markov game, and under what state and reward settings does a pure Nash equilibrium exist?

repo · soccer-markov-nash  |  118 tests  |  built on the CS 540 A10 assignment

The kickoff. 7×5 grid, 2 380 non-terminal states. Player 0 carries the ball and attacks the right edge; player 1 the left. Actions U D L R are chosen simultaneously; reward is +1 / −1 / 0, zero-sum.

The answer, in four lines

  1. 1Under the A10 move rule, a pure stationary Nash equilibrium exists at every state. Pure-strategy Nash Q-iteration solves the game exactly in 9 sweeps with no linear program at all.
  2. 2A coin-flip tie-break does not break this. Randomising who wins a contested square leaves the value function bit-identical to the deterministic game's.
  3. 3Littman's random move order does break it. On the 7×5 board, 94 of 2 380 stage games (3.9%) have no pure saddle, so no pure stationary equilibrium exists — and the effect is board-size dependent.
  4. 4Potential-based reward shaping preserves the equilibrium exactly; a naive per-step possession bonus changes it. The recommended solver is the hybrid: pure where possible, LP only where necessary.

The two solvers

The game is zero-sum, so at every state the stage game is a payoff matrix M(s)[a₀, a₁] = E[R + γV(s′)] and the Shapley (1953) fixed point is the minimax value:

V(s) = val(M(s)) = maxₙ minₖ₃ (pᵀM)[a₁]
        = minₚ maxₐ₀ (Mq)[a₀]

The Q = R + β Nash(Q′) update from the project notes is the same operator. Two stage solvers implement the two versions asked for:

A pure saddle point exists iff the maximin equals the minimax. When it does, the pure value is the minimax value, so the hybrid is exact; when it doesn't, the hybrid falls back to the LP for that state only.

Key finding

The deterministic and coin-flip value functions are identical — max |V_det − V_coin| = 0 for every γ. With optimal play neither player enters a contest it would lose deterministically, so the coin is never flipped on the equilibrium path.

It is not stochasticity that forces mixed strategies. It is the sequential coupling of Littman's random move order — where whether you steal the ball depends on who resolves first and on both players' targets — that creates matching-pennies sub-games with no pure saddle.

By board size — random move order

By reward setting

Potential-based shaping F(s,s′) = γΦ(s′) − Φ(s) with Φ = possession bonus + ball advancement:

  • V_shaped = V_base − Φ to machine precision; identical policies; identical no-saddle set. The equilibrium — pure or mixed — is unchanged.
  • It slows exact value iteration (9 → ~130 sweeps), because Φ is nonzero on the ~1 000 states where V_base = 0.
Caution

A non-potential per-step possession bonus is not invariant: a +0.05 bonus turns the kickoff draw into a +0.5 value for the carrier and changes the optimal policy. Shaping rewards for this game must be potential-based.

Can pure equilibria solve it efficiently?

Yes. On the deterministic and coin-flip games the pure solver is the exact solver — pure, hybrid and mixed return the same value function in 9 sweeps with zero LP calls. On the random game the hybrid is still the right tool:

The hybrid reproduces the full-LP value function to 4e−16 while solving an LP on only the ~4% of states that need one. The pure-only solver is a strict lower bound — it reports a kickoff draw when the game actually favours the initial carrier by 0.15, and sits up to 0.37 below the true value elsewhere. Efficient, but when a mixed equilibrium is the real answer, wrong.

Freeze then iterate

Solving a matrix game at every state on every sweep is wasteful. run_policy_iteration() solves each stage game only on its outer rounds and holds the strategies fixed for cheap linear evaluation sweeps in between — the notes' "don't recompute Nash every time".

On this small game the stage-matrix construction, not the LP, is the bottleneck — so cutting solves 4× doesn't cut wall-clock. The technique pays off where the notes expect: larger action spaces or general-sum games, where the equilibrium solve dominates the backup.

The equilibrium policy is worth playing

  • The Nash Q policy has a duality gap V0_br(s₀) + V1_br(s₀) < 1e−9 for every move order — no opponent can beat the game value.
  • Nash vs. Nash reproduces the value: forced draws in the deterministic and coin-flip games; a +0.157 empirical discounted return (vs. +0.150 computed) in the random game.
  • Best-responding to a guess about the opponent is fragile: the Part 2 best-response-to-the-scripted-opponent policy has exploitability 0.43 — worse than moving uniformly at random (0.39) once the opponent best-responds to it.

That last line is exactly the A10 competition's warning about non-equilibrium submissions. The equilibrium networks (scripts/a10_competition.py) are the principled answer — though a neural approximation is only as safe as its worst-fit state, so the script prints the trained network's exploitability and the student re-seeds until it is near zero.

Conclusion

For the soccer game as specified by A10, pure-strategy Nash equilibria are not just usable but sufficient and efficient: they exist everywhere and are found in a handful of sweeps with no linear programming. Pure equilibria fail only under Littman's sequential random move order, and even then only on ~4% of states of a large enough board. The hybrid solver — pure where possible, LP where necessary — is exact everywhere and pays the LP cost only where a pure equilibrium genuinely does not exist. Potential-based reward shaping leaves all of this untouched.
